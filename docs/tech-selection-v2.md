# 语音输入桌面端技术选型报告 · 第二版（定稿与实测）

> 作者：dogeheng ｜ 日期：2026-10-24 ｜ 状态：定稿，已按此实现 M1 ｜ 上一版：[tech-selection.md](tech-selection.md)

第一版报告对每个关键节点给出了三到四个候选方案。评审后的约束是：**只做 macOS**；**框架用 Tauri 2 + Rust**；**国内外都要能用**；**离线可用，同时用云端提高准确度**；云端统一走 **OpenRouter**；本地模型追求**首字延迟**，云端追求**准确度**，两者结合，做到“边说边出字、松开不等待”。本版记录在这些约束下的最终选择、选择理由和实测数据。第一版中的候选对比仍然有效，可作为以后调整的参考；与本版冲突的推荐以本版为准。

## 1. 定稿方案一览

| 节点 | 定稿选择 | 主要备选（第一版中已对比） | 选择理由 |
| --- | --- | --- | --- |
| 桌面框架 | **Tauri 2**（Rust 后端 + React/TypeScript 界面） | Electron、原生 Swift/AppKit | 内存与安装包小；敏感逻辑（密钥、音频、插入）全部在 Rust 中，网页层拿不到密钥；可直接调用 macOS 原生 API |
| 本地流式识别（预览） | **sherpa-onnx + 流式 Zipformer 中英双语**（int8） | whisper.cpp、Apple SpeechAnalyzer | 真正的流式模型，边说边出字；中英混说；Rust crate 静态链接，无外部动态库 |
| 本地精识别（离线最终结果） | **SenseVoice 2024-07-17 int8** | SenseVoice 2025-09-09、Whisper small/turbo、Paraformer | 实测 2024 版自带标点、数字规整和英文大小写，明显好于 2025 版；5 到 11 秒音频 160 到 350 ms |
| 语音活动检测 | **Silero VAD**（静音 0.3 s 切块） | WebRTC VAD、TEN VAD | 准确率高、模型约 2 MB；用于“边说边分块上云” |
| 云端识别 | **OpenRouter `/audio/transcriptions`，默认 Voxtral Mini Transcribe 3** | GPT Transcribe、Qwen3 ASR、Scribe v2、Deepgram Nova-3 等 7 个，可在设置里切换 | 12 个模型实测中，中英混说准确度与延迟综合最好；专有名词（Kubernetes、OpenRouter、Figma）全对 |
| 本地 + 云端融合 | **VAD 分块渐进上云 + 截止时间合并 + 迟到结果安全替换** | 纯云端、纯本地、松开后整段上云 | 长句在说话时就已大部分传完，松开后只等最后一块；网络差时自动退回本地结果 |
| 口语转书面语 | **规则层（始终生效）+ 按需触发的 LLM 整理（gpt-oss-20b）** | 每次都走 LLM、只用规则、Gemini Flash Lite | 规则层零延迟；只有出现语气词、改口、长段落时才调 LLM；gpt-oss-20b 不翻译、不乱改 |
| 全局快捷键 | **自研 Quartz CGEventTap**，单独按下修饰键触发（fn、右 ⌥、右 ⌘、右 ⌃） | Tauri global-shortcut（Carbon）、rdev、uiohook | Carbon 拿不到修饰键的“松开”，无法实现按住说；主动式 tap 可在录音中吞掉 Esc |
| 交互模式 | **混合模式（默认）**：按住说话、松开结束；轻点进入免提、再按结束；另有“仅按住”“按一下开关” | 只做按住说、只做开关 | 兼顾短句与长段口述；按住期间按其他键视为组合键，自动放弃，避免误触 |
| 状态反馈 | **不抢焦点的 NSPanel 胶囊浮窗**（tauri-nspanel）+ 菜单栏图标 + 系统橙色麦克风指示 | 普通透明窗口、仅菜单栏图标、系统通知 | 浮窗不夺走目标应用的焦点，跨桌面空间、全屏应用上可见 |
| 文本插入 | **剪贴板 + ⌘V，粘贴后恢复用户剪贴板**；密码框拒绝；无输入框时保留在剪贴板并提示 | AX 直接写入、逐字模拟键入 | 兼容性最好（含 Electron/Chromium 应用）；剪贴板标记为临时内容，不进入剪贴板管理器历史 |
| 迟到结果替换 | **用 AX 读光标位置与插入内容校验，确认安全才原地替换** | 不替换、无条件替换 | 用户已经继续打字或移动光标时绝不覆盖，只更新历史记录 |
| 密钥 | **macOS 钥匙串**（服务名 `voice-input-desktop`） | 加密配置文件、环境变量 | 不落盘、不打印、不进入网页层；界面只显示掩码 |
| 历史记录 | **SQLite，只存文字不存音频**，可关闭、可清空、按天数自动过期 | 不保存、加密存音频 | 方便找回和复制；关闭开关时立即清空 |
| 签名与分发 | **自签名证书 + Hardened Runtime**（开发与小范围试用）；正式分发换 Developer ID + 公证 | ad-hoc 签名、直接上 Developer ID | 证书哈希固定，重新编译后权限不失效；Bundle ID `com.peihengli.voiceinput` |

## 2. 一次听写的完整流程

```
按下快捷键 ──► 记录目标应用 ──► 打开麦克风 ──► 浮窗出现（录音中）
                                          │
            ┌─────────────────────────────┼──────────────────────────────┐
            ▼                             ▼                              ▼
   流式 Zipformer（本地）            Silero VAD 找停顿              音量电平
   实时字幕，首字约 0.2 s          每攒够 2.5 s 语音且遇到 0.3 s         → 浮窗波形
                                   停顿，立即切出一块：
                                   ├─ 上传 OpenRouter（云端精识别）
                                   └─ SenseVoice（本地精识别，并行）
                                          │
松开快捷键 ──► 只剩最后一块在途 ──► 等云端到截止时间（默认 1.0 s）
                                          │
            每一块取“云端结果，否则本地 SenseVoice 结果”，按顺序拼接
                                          │
                     规则整理：语气词、标点、中英空格、词典大小写、替换规则
                                          │
            需要时调 LLM 整理（最多等 1.2 s，超时先插入规则版，LLM 后台继续）
                                          │
            插入：拒绝密码框 → 剪贴板 + ⌘V → 恢复原剪贴板 → 浮窗显示结果
                                          │
            迟到的云端结果或 LLM 结果 → AX 校验光标仍在插入文字末尾 → 原地替换
```

设计要点有四条。第一，**用户永远不为云端等待超过截止时间**，超时就用本地结果，之后能安全替换再替换。第二，**云端和 LLM 的每一步都有硬超时**，任何网络故障都只会让结果“退回本地”，不会卡住。第三，**音频只在内存中**，分块上传后即丢弃，不写磁盘。第四，**防误触**：按下快捷键后 0.9 秒内又按了其他键，视为用户在按组合键（例如右 ⌘ + C），本次录音直接放弃、浮窗静默消失；录音中按 Esc 随时取消；没有检测到说话时提示“没有听到声音”，不插入任何内容。

## 3. 实测数据（本机 Apple Silicon，2026-10-24）

测试方法：用系统 TTS 合成中英混说、改口、纯英文三段音频，再拼接成一段带自然停顿的 26 秒长音频；基准工具 `vi_bench` 按真实语速把音频送入管线，模拟“边说边识别”。

| 场景 | 松开到拿到最终文字 | 文字来源 | 说明 |
| --- | --- | --- | --- |
| 26 秒长段落（3 处停顿） | **465 ms** | 全部云端 | 说话过程中已经切出并上传了 3 块，松开时只剩最后一块 |
| 5.5 秒英文短句 | 914 ms | 云端 | 云端 825 ms 返回，赶上 1 秒截止时间 |
| 7.4 秒中文改口句 | 1058 ms | 本地 | 云端未赶上截止时间，先上屏本地结果，随后云端结果到达并安全替换 |
| 本地 SenseVoice 精识别 | 160 至 410 ms | — | 5 至 12 秒音频，完全离线 |
| 流式预览首字 | 约 200 ms | — | 随说随出，用于浮窗实时字幕 |
| LLM 整理（gpt-oss-20b） | 400 至 1090 ms（平均约 700 ms） | — | 只在需要时触发；改口、语气词、中英混排 6 个用例全部正确 |

准确度方面，同一段中英混说，本地结果为“qubbernet 部署文档和 open route 的 API”，云端结果为“Kubernetes 部署文档和 OpenRouter 的 API”，**专有名词上云端明显更准**，这正是融合方案的价值所在。改口句“周四……不对，改成周五上午十点”经 LLM 整理为“我们周五上午十点再讨论这个方案，地点在三楼的会议室。”

## 4. 关键实现决策与踩过的坑

**模型版本。** SenseVoice 2025-09-09 新版在本机测试中英文全大写、不出标点、拼写错误较多，最终选用 2024-07-17 版。本地模型合计约 440 MB，下载时自动在 Hugging Face 与国内镜像 `hf-mirror.com` 之间切换；VAD 额外支持从 GitHub Releases 下载。

**LLM 整理只在需要时调用。** 规则层先判断文本里有没有语气词（嗯、呃、um、uh）、改口词（不对、我是说、sorry I mean）、序列词（第一、首先、first），或者文字较长（中文 120 字或英文 60 词以上）。都没有就不调 LLM，这样大多数短句松开后不到 1 秒就上屏。提示词明确要求“不翻译、不回答问题、只用改正后的说法替换被纠正的那一小部分”，并附了示例；输出若比输入短太多，视为异常，丢弃不用。

**中文排版规则。** 中文与英文字母之间加空格（“和 Alex 开会”），**数字与汉字之间不加空格**（“10点”“3楼”）；中文为主的句子把句末英文句点转为全角句号。词典中的英文词会统一大小写（例如 openrouter → OpenRouter）。

**快捷键的可靠性。** macOS 在回调过慢或用户输入时会关闭事件监听（tap），程序检测到后立即重新开启；辅助功能权限尚未授予时会定时重试，所以用户在引导中授权后**不需要重启 App**。当系统处于“安全输入”状态（密码框、部分终端）时，快捷键和插入都会被系统拦截，概览页会给出明确提示。

**签名。** 自签名证书放在独立的开发钥匙串 `voiceinput-dev`，该钥匙串的随机密码存在登录钥匙串中，因此签名过程不会弹窗。证书未加入系统信任设置，但 codesign 可以正常签名；签名的“指定要求”锁定证书哈希，所以每次重新编译后 macOS 仍认为是同一个 App，麦克风和辅助功能授权保持有效。开启 Hardened Runtime 后必须声明 `com.apple.security.device.audio-input`，否则麦克风会被静默拒绝。

**浮窗创建崩溃（已修复）。** 先创建带标题栏的 WebView 窗口、再把样式替换为无边框时，AppKit 会因 WKWebView 正在监听 `contentLayoutRect` 而抛出异常，导致启动即崩溃。正确做法是创建时就设 `decorations(false)`，样式只用 `add_style_mask` 追加 `nonactivating_panel`。另外，浮窗和托盘创建失败现在只记录日志，不会再让整个 App 退出。

**钥匙串读取不能放在主线程（已修复）。** 读取钥匙串时如果需要用户授权，调用会一直阻塞到用户点击为止；放在启动流程的主线程上，整个 App 会卡死。现在 Key 在后台线程读取，所有涉及钥匙串和网络的命令都是异步命令。

**自签名的已知限制。** macOS 按每次编译的代码哈希识别自签名 App 对钥匙串的访问，所以**每次重新编译或更新后，首次读取 Key 会弹出一次钥匙串授权**，点“始终允许”即可。在 App 内保存或更换 Key 时会由 App 重新创建钥匙串条目。换成 Developer ID 签名后，系统按团队 ID 识别，这个弹窗就不会再出现。麦克风和辅助功能授权不受影响，因为它们按证书识别，重新编译后依然有效。

## 6. 隐私与信任的落实情况

| 承诺 | 实现方式 |
| --- | --- |
| 只在用户按住快捷键（或免提模式）期间录音 | 麦克风输入流只在录音期间打开，系统菜单栏的橙色麦克风指示与录音状态完全一致；最长录音 6 分钟自动结束 |
| 用户能明确感知录音 | 底部浮窗显示红点与波形；主窗口侧边栏显示“正在录音 / 麦克风未使用”和“本地 + 云端 / 仅本地” |
| 音频不落盘 | 音频只在内存中处理；历史只保存文字、来源、时长和延迟 |
| 可以完全离线 | 关闭“使用云端识别”后音频不出本机，本地模型完整可用 |
| 密钥安全 | 只存在钥匙串；不写文件、不打日志、不传给网页层；界面只显示掩码 |
| 不误插入敏感位置 | 焦点是密码框时拒绝插入；系统安全输入状态下给出提示 |
